# sales-dashboard-using-power-bi- 
# Summary of findings
•Title:Super store sales dashboard using power bi 
• tools & sources:

• Microsoft power bi for data cleaning and visualization.
•super store dataset.xlsx dataset used for creating dashboard 

•Insights from dashboard:
1. Total Sales: The total sales amount is 1.57 million.


2. Monthly Trend: Sales peaked in December, with noticeable dips around April to August.


3. Regional Performance: The West region leads in sales, followed by East, while South has the lowest.


4. Category Distribution: Technology is the top-performing category (36.4%), followed by Office Supplies (32.3%) and Furniture (31.3%).
